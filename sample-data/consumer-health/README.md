# Consumer Health demo data (fictional)

Every company, brand, product and number in these files is invented for demonstration and testing. 'Verdant Health' is the fictional focus company.

| File | What it contains |
|---|---|
| market_report_2025.pdf | Market report with text, a table, a chart image and a footnote |
| sales_dataset.xlsx | Monthly sales 2023–2025 by product, category, format, channel and region (with deliberate quality issues) |
| competitor_dataset.csv | Competitor products with category, format, price, rating and sales |
| marketing_dataset.csv | Monthly media spend, impressions, clicks, conversions and revenue by channel and campaign |
| product_dataset.xlsx | Own portfolio, plus a Plan vs Actual sheet |
| strategy_2024_previous.docx | Previous strategy |
| strategy_2026_proposed.docx | Proposed strategy |
| business_review_2025.pptx | Slides with a native chart and speaker notes |
| survey_purchase_drivers.png | Screenshot of a bar chart (tests OCR / visual interpretation) |
